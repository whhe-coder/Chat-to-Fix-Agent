# 2026-11-13 T-1：卡在第 1 步，模型登录过期

**结果**：任务在第 1 步（取讨论）停住，没有建单，没有任何产物。原因是本机 Claude Code 的登录过期。

## 环境

| 项 | 值 |
| --- | --- |
| Agent 版本 | main `0d80fd3`（当时本地是 PR #7 分支，Agent 代码和 main 相同） |
| 模型 | 没有 `ANTHROPIC_API_KEY`，流程 bot 走本机已登录的 Claude Code |
| 入口 | 模拟页面（`npm start`），频道 `CLOCAL` |

## 步骤

| 时间 | 步骤 | 结果 |
| --- | --- | --- |
| 13:39:56 | 第 1 步，主 bot 调模型 | ❌ `LOCAL_AGENT_ERROR: Failed to authenticate: OAuth session expired and could not be refreshed` |

任务一直显示“处理中”，实际已停住；停掉之前发件箱没有消息（停掉后才有 1 条“已停止”，见下方原始数据）。

## 原因（已核实）

- 本机 Claude Code 命令行的登录过期。
- Agent 是从 Claude 的沙箱里启动的，沙箱读不到钥匙串里的登录信息；重新登录后从沙箱启动仍然失败。

## 处理

- 在自己的终端里 `/login` 重新登录，停掉 T-1，改在自己的终端里 `npm start`。之后的 T-2 模型调用正常。
- 以后 Agent 一律在自己的终端里启动。PR #8 起所有 bot 改用 `ANTHROPIC_API_KEY`，不再依赖 Claude Code 登录。
