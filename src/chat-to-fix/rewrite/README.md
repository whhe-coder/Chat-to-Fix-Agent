# rewrite/

当年把 DS Bot 裁成 `bot/` 时留下的统计和脚本：哪些文件在用、哪些删了、为什么。查 `bot/` 的来历时看，平时不用看。

| 文件 | 放的是什么 |
|---|---|
| `INVENTORY.md` | 统计报告（中文）：`bot/` 里真正加载的文件、删掉后测试结果不变 |
| `INVENTORY.en.md` | 同一份报告的英文版 |
| `bot-files.tsv` | `bot/` 每个文件的行数、归类（用到 / 没用到）和处理（保留 / 删除） |
| `salvage-trial.tsv` | 试验：保留的 `bot/` 测试在裁剪后的通过情况 |
| `inventory.mjs` | 生成上面统计的脚本（顺着 import 找运行时文件） |

谁调它：没有代码用它。只是记录，数字是 2026-11-12 当时的；不要为了"保持最新"去改。
